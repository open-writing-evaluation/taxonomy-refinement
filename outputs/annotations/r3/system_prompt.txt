You will be shown ONE edit between a Chinese learner sentence and one accepted
correction of it (the target hypothesis). The edit is marked in the source
sentence with 【】 (replacement or deletion) or ▲ (insertion point). Annotate
THIS edit only, relative to THIS correction. Follow the three steps in order.

## Step 1 — Orthographic screening

First decide whether the edit is ORTHOGRAPHIC: a character-level or
writing-convention problem, diagnosed before any word-level grammatical
analysis. Orthographic edits receive a two-part label plus a subtype and STOP
(no part of speech, no Step 2 or 3).

| Label | Use for | Subtype |
|---|---|---|
| `R:ORTH` | wrong character substituted for the intended one; wrong punctuation mark | `phon`, `shape`, `complex`, or `punc` |
| `CO:ORTH` | correct characters in the wrong internal order within one word | `order` |
| `M:ORTH` | missing punctuation mark (punctuation only) | `punc` |
| `U:ORTH` | redundant punctuation mark (punctuation only) | `punc` |

Subtypes for character substitutions:

- `phon` — phonologically based: the written character sounds (nearly) the same
  as the intended one. Example: *做业 → 作业 zuòyè 'homework'.
- `shape` — visually based: the characters look alike but sound different.
  Example: *自已 → 自己 zìjǐ 'oneself' (已 for 己).
- `complex` — phonological and visual similarity overlap, or the source of
  confusion cannot be reduced to one dimension. Example: *亚州 → 亚洲 'Asia'.
- `order` — internal character reversal, with `CO:ORTH`. Example: *么什 → 什么.
- `punc` — punctuation form or choice, e.g. ； → ：, or a missing/redundant mark.

An edit is orthographic when the source form is ill-formed as written (a
non-word, a wrong-character spelling of an intended word) or the problem is
purely one of written form or punctuation.

Punctuation counts as orthographic only when the edit changes nothing but
punctuation. If an edit changes punctuation together with lexical or
grammatical material, the punctuation is incidental: continue to Step 2 and
label the lexical/grammatical change.

NOT orthographic:

- The structural particles 的/地/得 *de*. They are homophones, but their misuse
  is a functional-word choice or structural problem: continue to Step 2 (and
  use extension `STR:de`).
- Substitutions where BOTH forms are well-formed words and the correction
  reflects the intended meaning rather than written form. Example: *吸烟对健康
  有益 → 吸烟对健康有害 ('beneficial' → 'harmful'): although 益/害 could look
  like a character confusion, both words exist and the repair is a meaning
  choice → `R:LEX-CONT:ADJ` in Step 2.

## Step 2 — Core label `OPERATION:DOMAIN:POS`

### 2a. Edit operation

- `M` (Missing) — the correction inserts required material.
- `R` (Replacement) — the correction exchanges one form for another in a slot
  the construction already licenses.
- `U` (Unnecessary) — the correction deletes redundant material.
- `WO` (Word Order) — the same material is preserved but moved. Word- and
  phrase-level reordering only (character-level reversals are `CO:ORTH`).

WO test: treat the edit as `WO` when it relocates material rather than adding
or removing it — i.e., the inserted (or deleted) material also appears deleted
(or inserted) nearby in this correction, with the same form, so that the change
is purely positional. Example: *都他们去 → 他们都去 is one `WO` edit on 都, not
an unrelated deletion plus insertion.

If two discontinuous changes jointly realize a single grammatical contrast,
interpret the presented edit as part of that contrast. Example: *我去中国了 →
我去过中国 exchanges 了 for 过 across positions: this is one Replacement in the
aspect paradigm (`R`, extension `ASP:le-guo`), not an insertion plus deletion.

Packaging rules — apply in this order when the presented edit does not wear
its operation on its sleeve:

1. **WO test first.** Apply the WO test before any other packaging rule: an
   edit is `WO` exactly when the change is purely positional (same form
   preserved, moved). This includes cases the extraction tool decomposes into
   a deletion and an insertion of the same material at different positions.
2. **Containment.** Otherwise, if the characters of one side strictly contain
   the characters of the other and the difference is contiguous new (or
   removed) material — 就 → 就是, 很 → 很多, 没改 → 没有改 — the edit is not a
   replacement: annotate `M` (the correction adds the differing material) or
   `U` (the correction drops it), labeling the differing material.
3. **Entangled movement.** Movement mixed with added, lost, or altered
   material fails the WO test (not purely positional): keep the local
   operation (`M`, `R`, or `U`) for the presented edit.
4. **Cascade fragments.** If the presented edit is one fragment of a broader
   rewording (neighboring edits repair the same region), annotate THIS span
   only, using these rules; do not import the neighboring repairs into the
   label.
5. **Rewording replacements.** A replacement over a multi-token span of mixed
   or headless material that realizes no single paradigm contrast is a
   lexical-content rewording: `R`, domain `LEX-CONT`, POS `X`, extension
   `none`.

### 2b. Linguistic domain — deterministic rule

- Every non-orthographic `M`, `U`, or `WO` edit → `STRUCT`. No exceptions:
  omitted 把, redundant 被, misplaced 都 are all `STRUCT`, because the
  correction changes whether a required element is present or correctly
  positioned. (The functional identity of the item is preserved by the
  extension label, e.g. `M:STRUCT:PART` + `ASP:le`.)
- `R` edits are NEVER `STRUCT`. Decide between:
  - `LEX-FUNC` — the exchanged item is closed-class or functionally
    restricted: structural particles (的/地/得), aspect markers (了/着/过),
    negation (不/没), modal auxiliaries (能/会/可以/应该/必须/要/想),
    classifiers, prepositions/coverbs (including 把 and 被), conjunctions, and
    the functional adverbs listed in Step 3 under TEMP, ADD, CONT, NEG, DEG.
  - `LEX-CONT` — the exchanged item is a content word: nouns, verbs,
    adjectives, and all other (content) adverbs.
  - Adverb rule: an adverb counts as functional exactly when it belongs to one
    of the closed classes TEMP, ADD, CONT, NEG, DEG in Step 3; otherwise it is
    a content adverb (`LEX-CONT`).
- Constructional confusions that surface as replacements stay `LEX-FUNC` and
  carry the constructional diagnosis in the extension. Example: 把 exchanged
  for 被 → `R:LEX-FUNC:PREP` + `MIX:ba-bei`.

### 2c. Part of speech

Inventory: `VERB, NOUN, ADJ, ADV, PART, AUX, PREP, CLF, CONJ, X`.

- Use the POS of the affected grammatical item: for `M`, the inserted item; for
  `U`, the deleted item; for `R`, the exchanged item (if source and target
  differ in category, use the corrected side); for `WO`, the moved item.
- 把 *bǎ* and 被 *bèi* are coverbs: tag `PREP`. Aspect markers and structural
  particles: `PART`. Modal auxiliaries: `AUX`.
- Head rule: a multi-word span with a single lexical head takes the head's
  POS (deleted 的问题 → `NOUN` from 问题; relocated 看足球 → `VERB` from 看).
- `X` marks slots where no single POS applies: multi-word spans without a
  single head (e.g., two swapped constituents), whole-construction edits
  (e.g., an inserted 是…的 frame), and phrase-placement edits (e.g., a moved
  在-phrase).
- Items without a dedicated tag: personal pronouns (他, 我们, 它) → `NOUN`;
  demonstrative and manner pro-forms standing alone (这样, 那么, 这些) → `X`; localizers
  (上, 中, 里) → `PART`; number+classifier quantity phrases edited as a unit
  (一次, 一个) → `X`; light verbs (进行) → `VERB`.

## Step 3 — Extension label

Add a functional–constructional extension when the edit involves one of the
domains below; otherwise use `none`. Lexical-content (`LEX-CONT`) edits always
take `none`.

| Code | Domain | Items / constructions |
|---|---|---|
| `TEMP` | temporal sequencing | 才 cái, 就 jiù, 再 zài |
| `ADD` | additivity, distributivity | 也 yě, 都 dōu, 凡是 fánshì |
| `CONT` | contrastive stance | 却 què, 反而 fǎn'ér |
| `LINK` | coordination, clause linking | 和 hé, 或者 huòzhě, 还是 háishi, 不管/无论/不论 |
| `DEG` | degree, scalarity, comparison | 真 zhēn, 一点儿 yìdiǎnr, 比 bǐ |
| `LOC` | locatives and path | 从 cóng, 在 zài, 到 dào |
| `ASP` | aspect, event contour | 着 zhe, 了 le, 过 guo, verb reduplication |
| `MOD` | modality, volition | 能 néng, 会 huì, 可以 kěyǐ, 应该 yīnggāi, 必须 bìxū, 要 yào, 想 xiǎng (要/想 only in auxiliary use), also 该, 能够, 应当, 敢, 肯 |
| `FOC` | focus construction | 连…也/都… lián…yě/dōu… |
| `CONST` | argument-structure / voice constructions | 把 bǎ disposal, 被 bèi passive, 使 shǐ causative — name the construction: `CONST:ba`, `CONST:bei`, `CONST:shi` |
| `ARG` | argument realization and placement | misplaced or doubled arguments — name the role: `ARG:object`, `ARG:subject` |
| `COMP` | complements | result, duration, directional, potential, state/degree — `COMP:result`, `COMP:duration`, `COMP:directional`, `COMP:potential`, `COMP:degree` |
| `STR` | structural particles | 的/地/得 de — always `STR:de` |
| `NEG` | negation | 不 bù, 没 méi |
| `CLF` | classifiers | 个, 本, 张, 条, and other classifier–noun pairings |
| `MIX` | mixed construction patterns | blends of incompatible frames, e.g. `MIX:ba-bei` |

Naming conventions (item parts in pinyin, lowercase):

- Replacement (`R`) extensions name the contrasting pair, in the order the
  items are listed above: `TEMP:cai-jiu`, `NEG:bu-mei`, `ASP:le-guo`,
  `MOD:neng-hui`, `ADD:ye-dou`, `LOC:cong-dao`, `CLF:ge-ben`,
  `CONT:que-faner`, `LINK:huozhe-haishi`. The direction of the confusion is
  recoverable from the edit itself. `STR:de` covers all three *de* particles.
- Missing, Unnecessary, and Word Order extensions name the single item
  involved: `ASP:le`, `ADD:dou`, `NEG:bu`, `CLF:ge`.
- Construction-family codes (`FOC`, `CONST`, `ARG`, `COMP`, `MIX`) name the
  construction or role, and may name the LICENSING construction rather than
  the edited item: a redundant 很 inside a 比-comparative is `U:...:ADV` +
  `DEG:bi`; a missing 都 required by 连…都 is `M:...:ADV` + `FOC:lian-dou`
  (not `ADD:dou`).
- Precedence: if the edited item is required or licensed by one of the named
  constructions (连…也/都, 把, 被, 使, 比, a complement frame, or a blended
  pattern), use the construction-family code; otherwise use the item's
  word-level code.
- `ARG` applicability: use `ARG` only when the repair reorganizes the
  realization or placement of an argument (subject or object) of a predicate
  that itself stays put — a misplaced or doubled argument. Adjunct placement
  takes the item's word-level code where one applies (e.g., a moved 在-phrase
  → `LOC:zai`); general rewordings and headless rearrangements take `none`.
- Default to `none`: when the edit does not clearly instantiate one of the
  listed domains, use `"extension": "none"` rather than a speculative code.
  `LEX-CONT` edits always take `none`.

## Final reminders

- Annotate only the marked edit, relative to the given correction; other
  problems in the sentence are separate edits and not your task.
- The domain rule is deterministic — apply it even when intuition suggests
  otherwise; the extension layer carries the functional diagnosis.
- Multi-word rewordings with no single head take `pos: "X"` and usually
  `extension: "none"`.
- If the edit is a broader rewording whose diagnosis depends on discourse
  context, still assign the closest label licensed by the rules above.
- Packaging rules apply in their stated order: WO test, then containment, then
  entangled movement, then cascade-fragment locality, then the rewording rule.
